# Brochure digital — Comercializadora UB Cuarenta

Sitio web estático, responsive y listo para publicar con GitHub Pages. No requiere instalación, compilación ni dependencias.

## Publicación en GitHub Pages

1. Cree un repositorio nuevo en GitHub.
2. Cargue **todo el contenido de esta carpeta** en la raíz del repositorio.
3. Abra `Settings` → `Pages`.
4. En `Build and deployment`, seleccione `Deploy from a branch`.
5. Seleccione la rama `main`, carpeta `/ (root)` y pulse `Save`.
6. GitHub mostrará la dirección pública después de unos minutos.

La estructura debe conservarse así:

```text
index.html
og.png
.nojekyll
assets/
  brand/
  photos/
```

## Actualizaciones

- Edite textos y estructura en `index.html`.
- Reemplace imágenes dentro de `assets/` conservando sus nombres.
- Para una vista previa local, abra `index.html` en el navegador.
