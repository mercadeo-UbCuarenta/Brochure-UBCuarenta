# Auditoría del brochure digital

Fecha: 28 de julio de 2026

## Resultado general

El brochure está listo para publicarse como sitio estático en GitHub Pages. La versión auditada contiene seis secciones, navegación por anclas, contenido responsive, imágenes locales, información de contacto y una presentación estática de presencia comercial.

## Verificaciones realizadas

- HTML con idioma español y codificación UTF-8.
- Un único encabezado principal `h1` y jerarquía secundaria consistente.
- Seis secciones identificables: Inicio, Quiénes somos y trayectoria, Marcas, Capacidades, Presencia y Contacto.
- Todas las imágenes cargan y tienen texto alternativo.
- Enlaces de correo, teléfono y sitio corporativo configurados.
- Sin desbordamiento horizontal en escritorio ni en vista móvil de 390 px.
- Navegación principal adaptada para dispositivos pequeños.
- Enlace para saltar al contenido y foco visible para navegación con teclado.
- Funcionamiento sin frameworks, bases de datos ni servicios externos.

## Optimizaciones aplicadas

- Fotografías convertidas a WebP para reducir el peso total.
- Logos principales redimensionados y comprimidos.
- Peso aproximado del sitio reducido a 3,3 MB.
- Archivo `.nojekyll` incluido para evitar transformaciones de GitHub Pages.
- Metadatos para vista previa social incluidos.
- Mapa interactivo retirado y reemplazado por cifras estáticas por ciudad.

## Información comercial mostrada

- 22 tiendas en total.
- 18 tiendas Levi’s.
- 4 tiendas Desigual.
- Bogotá: 16 tiendas.
- Ibagué: 3 tiendas.
- Chía: 2 tiendas.
- Tunja: 1 tienda.

## Recomendaciones posteriores a la publicación

- Actualizar `og:image` y agregar la URL absoluta cuando se conozca la dirección final de GitHub Pages.
- Vincular un dominio corporativo si se requiere una dirección más institucional.
- Revisar periódicamente cifras, tiendas, teléfonos y correos.
- Mantener copias optimizadas de cualquier fotografía nueva.
